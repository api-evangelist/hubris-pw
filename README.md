Hubris is a Russian-language gateway to over 600 AI models, including GPT, Claude, Gemini, DeepSeek, and many others, all accessible via a single OpenAI‑compatible API. It offers a unified chat interface for all models, supports payment by Russian cards, SBP, or corporate accounts, and positions itself as a comprehensive AI model hub.

**Areas:** AI · Gateway · Models · OpenAI-compatible · Russian

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Hubris: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
